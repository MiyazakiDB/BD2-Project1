# Tests de Funcionalidad Multimedia

Este directorio contiene pruebas y demostraciones para la funcionalidad de búsqueda multimedia implementada en el sistema.

## Estructura de archivos

- `mnist_test.py`: Prueba simple con un imagen MNIST comparada con otras del mismo dataset para la funcionalidad básica de multimedia

## Requisitos

Asegúrate de tener instaladas todas las dependencias:

```bash
pip install -r requirements.txt
```

## Pruebas simples

Para ejecutar pruebas simples sin dependencias complejas:

```bash
python tests/multimedia/mnist_test.py
```

Esta consulta devolverá los registros más similares a la imagen de consulta.
